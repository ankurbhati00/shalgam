# Imagery

Product, category and promotional photographs in this folder are sourced from
[Pexels](https://www.pexels.com) under the Pexels License, which permits free
use and modification without attribution. They are bundled with the mock
backend purely to make the demo catalogue feel real; a production deployment
would serve imagery from its own CDN.

Brand names shown in Shalgam (Gokul, Rasoi Queen, Mithaas, Safai Pro, …) are
fictional.
