# Design tokens

Tokens live in `@shalgam/tokens` (`src/tokens.css`) and are consumed two ways:

1. **Tailwind utilities** — every `--color-*`, `--radius-*`, `--shadow-*` and `--animate-*` entry under `@theme` becomes a utility class (`bg-brand-400`, `rounded-xl`, `shadow-md`, `animate-fade-in`).
2. **CSS custom properties** — semantic tokens (`--color-surface`, `--color-text-muted`) are read directly in CSS, charts and SVG, so themes work everywhere.

## Primitive scales

- **Brand** `brand-50 … brand-950` — lime/chartreuse. `400` is the CTA colour; `800` is the text colour on light backgrounds (AA contrast).
- **Neutral** `neutral-50 … neutral-950` — warm, stone-tinted greys.
- **Status** `success`, `warning`, `danger`, `info` — each with `50/100/200/500/600/700/900`.
- **Tints** `tint-lime | mint | sky | lavender | peach | butter | rose` — pastel backgrounds for category tiles and avatars.
- **Chart** `chart-1 … chart-6` — hue-separated categorical palette for data visualisation; semantic (re-mapped for dark surfaces) and emitted statically so chart libraries can read `var(--color-chart-n)`.

## Typography

`--font-sans` is **Plus Jakarta Sans Variable**, a friendly geometric sans with clear numerals; tables opt into tabular figures via the `tabular` utility. Sizes follow Tailwind's scale plus `text-2xs` (11px) for dense admin labels.

## Radius

| Token                  | Value       | Use                          |
| ---------------------- | ----------- | ---------------------------- |
| `--radius-xs`          | 4px         | Checkboxes, tiny chips       |
| `--radius-sm`          | 8px         | Inputs (compact), menu items |
| `--radius-md`          | 12px        | Inputs, table containers     |
| `--radius-lg`          | 16px        | Cards, popovers              |
| `--radius-xl`          | 20px        | Dialogs, hero cards          |
| `--radius-2xl` / `3xl` | 28px / 36px | Sheets, promo tiles          |
| `--radius-full`        | 9999px      | Buttons, badges, steppers    |

## Elevation

`shadow-xs` (inputs) → `shadow-sm` (cards) → `shadow-md` (hover, popovers) → `shadow-lg` (menus, drawers) → `shadow-xl` (dialogs). `shadow-brand` is a lime glow reserved for the floating cart button.

## Motion

Durations: 140 ms (fast), 180 ms (base), 260 ms (slow). Easings: `--ease-out-soft` for entrances, `--ease-in-out-soft` for exits, `--ease-spring` for the add-to-cart pop. Named animations: `fade-in/out`, `scale-in/out`, `slide-up/down`, `slide-in-left/right`, `shimmer`, `pop`.
